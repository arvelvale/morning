## 设计基调（从原型提炼，落代码时对照）

- **低 chrome**：下划线式分段、发丝线分隔、批注式单列，不堆卡片；
- **内容即书页**：信箱是信笺（朱丝栏 + 火漆印 + 衬线信文）、片场是水牌、通话是剧本；
- 日夜双主题同构，金（`#B8860B` 系）作为点缀色；
- 克制、安静、有纸感——与 `frontend-demo/src/design-system/` 的语义 token 对齐。

## 已采纳的设计决策（Decision Log）

### 2026-07-30 · 信箱回归「游戏邮箱」两层结构

- **背景**：线上信箱曾被做成四分类（今日待启/桌宠来信/三日寄存/长久珍藏），
  附带来信每日 1–2 封上限与 3 天寄存期，偏离了「简简单单像游戏邮件」的最初设想。
- **决策**（以本目录原型的「屏二：信箱」为基准）：
  1. 信箱只有两层：**来信**（信笺 + 往期来信列表）与**思绪**（办/想/情/景单字章批注列表）；
  2. 来信**不设每日数量上限**，仅保留来源幂等（同一来源同天一封）；
  3. 取消「三日寄存」：待办/灵感/情绪/片段统一进思绪层，**默认保留一个月**，到期真删除；
  4. 珍藏改名「我留下的」，作为来信页内的安静入口，不做并列分区。
- **落地**：前端 `frontend-demo/src/screens/mailbox/MailboxScreen.tsx` 重构；
  后端 `EPHEMERAL_TTL_DAYS=30`、`LetterStore` 移除每日槽位上限；
  同步更新 `Morning项目功能文档-精简版.md` §4.3、`backend/docs/api-design.md` §8 等。
  详见 Obsidian 笔记 `D:\文档存放\wisdom\Aerchen\Morning-项目梳理\`。
