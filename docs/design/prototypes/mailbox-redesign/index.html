信箱改版原型

左边可以点：点“有句话”那封 → 读信 → 进去说说看；点晚间信 → 收到啦 / 留下；点“3 张小纸条”展开。

乱信太多太乱 → 按天归组，小纸条叠起来

正经的信（晚间信、有句话、周报）单独成卡；“该歇一歇了”“睡前碎碎念”“提醒”这类一两句话的，叠成一叠“小纸条”，点开才展开，首页不再被同一句话刷屏。

长信卡片太长 → 列表只给两行，点开再读

列表里只有标题、两行预览、谁写的、几点。三个按钮收成一排：主按钮“收到啦”，回一句和留下变成图标。

找往期不好找 → 筛选 + 按日期分组

按类型筛（晚间信 / 有句话 / 周报 / 小纸条 / 我留下的），按天分组并显示时分；右上角搜索按标题和正文找。

丑视觉 → 大信封缩成一条“今晚的信”

原来的大信封占半屏，改成一条：今晚 21:30 的信，米露还在写，并有一个“在写”的小动效。信纸保留手写字体和纸纹，其余用 App 现有的颜色。
