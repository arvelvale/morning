# 喵灵 App 改版第二稿：米露的夜空 × 接住计数 × 真实界面引导

日期：2026-10-07。用户确认的交互设计稿：`design-demos/app-redesign/index.html`（私有 Artifact 同步发布）。
本文与 `2026-07-25-morning-frontend-visual-redesign.md` 冲突的地方以本文为准，具体是那份规格的 §4.1 日间基础色、§4.3 字体、§7.1 陪伴首页、§7.2 登录与引导；其余章节（响应式框架、组件体系、信箱 / 场景 / 个人页的结构）继续有效。

## 1. 要解决的四个问题（用户原话归纳）

1. 大量米白、浅金、白色，层级不足，页面单调。
2. 猫咪 IP 像插图，没有和产品交互结合。
3. 首页信息层级不明显，「接住了几件事」这个核心概念没被表现出来。
4. 不要独立的多页轮播引导；要在真实首页上做 Spotlight / Coach Marks，**用户真的完成操作才推进**，随时可跳过，提示简短、有陪伴感。

## 2. 颜色（`src/design-system/tokens.ts`）

层级靠明度拉开：

| 角色 | 日间 | 夜间 | 用在哪 |
|---|---|---|---|
| 纸底 `background` | `#F3EFE9` | `#141127` | 只做底色 |
| 卡片 `surface` | `#FFFFFF` | `#1F1B39` | 内容容器 |
| 墨色 `textPrimary` | `#211D32` | `#F1EDF8` | 正文、标题 |
| 主操作 `accent` | `#2D2754` 深靛 | `#BBAFFF` 浅薰衣草 | 主按钮、底栏选中胶囊、链接 |
| 夜空 `sky` → `skyDeep` | `#2D2754` → `#1C1833` | `#231C4F` → `#0D0B1C` | 首页主卡、登录页天空（日夜都是深色） |
| 星星 `star` | `#FFD467` | 同 | **只给被接住的东西**：计数、星光、引导高亮圈 |
| 待办 `todo` / 灵感 `idea` / 情绪 `mood` / 片段 `frag` | 番茄 `#E5603F` / 柠檬 `#C98E00` / 薰衣草 `#7563DE` / 薄荷 `#23917A` | 提亮版 | 四类碎片，各带一个 `*Soft` 浅底 |

规则：金色不再作为通用强调；四类色只表达类别；页面上最重的一块永远是夜空主卡。

## 3. 字体

- 标题与米露说的话用 **Miaoling Kai**（霞鹜文楷 Screen 的 GB2312 子集，3.5MB，`assets/fonts/MiaolingKai.ttf`，生成脚本 `scripts/build-font-subset.py`）。按 OFL 保留字体名条款改名分发，授权见 `assets/fonts/OFL.txt`。
- `textStyles.pageTitle / sectionTitle / display / emotionalTitle / petVoice` 走手写体，字重一律 400（只有一个字重）。
- 正文、按钮、输入框、聊天内容保持系统无衬线。
- 加宽字距只给两三个字的短标签；整句的环境行 `ambient` 收到 0.6。

## 4. 首页「今日」（`src/screens/today/`）

自上而下：

1. 问候（日期 · 周几 · 节气 + 「晚上好」）；右侧语音通话、日夜切换。
2. **米露的夜空主卡**：左上「今天接住了 **N** 件事」是全页最大的字（72px 星星色），下面按四类拆开；右下是抱着星星的米露（夜间配色，眼睛和星星发光）。点数字展开「今天接住的」。
3. **接下来**：两张卡，「明早 8:00 · 提醒你 xx」和「今晚 21:30 · 米露的信」。
4. 唯一的主操作：**一股脑倒出来**（输入框 + 麦克风）；旁边「+」收着其他聊法（自由聊聊、放不下的事、回看片段、翻翻往日）。

猫和操作的绑定：

| 用户动作 | 米露 |
|---|---|
| 打开「倒出来」 | 竖耳朵（listening）；每敲一个字耳朵抖一下 |
| 点「倒给米露」 | 话拆成纸条沿弧线飞进它抱着的星星 |
| 后端每分类好一条 | 数字跳一下、星星闪一下、它被戳一下；全部完成后开心一会儿 |
| 等待分类 | 思考（thinking） |
| 戳它 | 反应 + 一句话 |
| 引导进行中 | 视线跟着被高亮的元素走（pet-rig 的 `look` 参数） |

数据：「今天接住的」= 待办 / 灵感 / 情绪 / 片段四个存储里今天（本机时区）新增的条目，本机缓存兜底（`caught.ts`）。「明早提醒」= 把待办截止时间设为明早 8 点，并在手机上排一条本地通知；后端记忆走版本链，改一次会换新 id。

## 5. 新手引导（`src/guide/`）

- 不再有独立教程页。登录 / 注册后直接进真实首页，本设备第一次进首页时自动开始；「我的 → 再走一遍新手引导」可重走；预览用 `?screen=companion&guide=1`。
- 遮罩挖洞只亮一个真实元素，提示框由米露说一句话 + 一行「要做什么」。点暗处不推进，米露说「先试试亮着的地方～」；右上角「跳过引导」随时可用。
- 六步，每步都要用户真的做：

| # | 亮哪里 | 米露说 | 推进条件 |
|---|---|---|---|
| 1 | 首页的米露 | 嗨，我是米露。先戳我一下？ | 戳它 |
| 2 | 倒出来输入框 → 打开后亮整个抽屉 | 心里乱糟糟的时候，都倒给我。/ 随便说，不用整理。 | 发出一次倾倒并分类完成 |
| 3 | 计数 | 接住了 N 件。看看我放哪儿了？ | 点开数字（没接住任何东西则跳过） |
| 4 | 第一条待办的「明早提醒我」 | 这件事，明早 8 点我来叫你？ | 设好提醒（没有待办则跳过） |
| 5 | 底栏「信箱」 | 今晚，我会把今天写成一封信。 | 进信箱 |
| 6 | 信箱顶上的「今晚的信」 | 信会放在这儿。到点再拆哦。 | 摸一下信封 |

- 引导时「倒出来」抽屉里会出现三句示范（待办 / 情绪 / 灵感各一），点一下就加进输入框。
- 片场不进第一次引导：第一天用不到，等第一封剧场邀请时再单步提示（未做）。

## 6. 登录

上半截是夜空，米露坐在里面：点用户名它竖耳朵（「我在听～」），输密码时捂眼（「我不看！」，`shy` 状态），点显示密码它问「那我可以看了？」，提交时思考。

## 7. 底栏

选中项是深靛实心胶囊垫在图标下，切换时弹性滑过去；图标「今日」改为星星。
