# 2026-09-02 开发日志

## 官网落地页：喵灵 Landing Page 上线 yingjiapp.com

### 第一层（产品语义）

**做了什么。** 喵灵有了正式官网原型并已真实上线：https://yingjiapp.com/ 。整页按「进入米露的世界」组织：首屏是真实的米露角色（会呼吸浮动、会随机眨眼），周围漂浮着「明天要交的东西…」「那句话,是不是说错了」这类思绪碎片；下滚时米露缓缓缩小退場，依次进入四个产品故事——倾倒思绪（对话面板里混乱的一段话被整理成三条待办）、记忆星河（散落的记忆便签向米露汇聚）、桌面伙伴（模拟桌面角落的米露递出提醒卡片，附静坐/打盹/挥手三态）、场景重演（路灯下两个人影与陪伴在侧的米露，视觉小说式对话框）；结尾回到安静夜晚，米露坐在发光的星星旁，再次给出两个下载按钮。首屏与下载区的鸿蒙/安卓按钮视觉等级一致，且**都能下载真实安装包**。

**为什么这样做。** 域名 yingjiapp.com 此前挂的是栖光项目的展示页，本次按决策改作喵灵官网。视觉上刻意避开 SaaS 官网模板（不做卡片网格、不用 AI 感紫渐变），配色取自品牌 logo 的深夜蓝紫 + 暖黄星光 + 一点粉，角色全部使用仓库里真实的米露美术（v3 白色长毛猫），让第一眼建立的是「喵灵的世界」而不是「又一个 AI 工具」。工程上按用户要求用 React + TSX 重写（第一版静态 HTML 仅作方向确认用，保留为 `landing/static-v1.html`），组件按区块拆分，避免单文件堆砌。

**核心数据流。** 纯静态站点：Vite 构建产物 → 服务器 nginx 直接托管，无后端依赖。安装包放在站点 `/dl/` 下同源分发（避开 HTTPS 页面引用 HTTP 下载的混合内容拦截）：安卓包与 App 内更新通道是同一份产物（SHA-256 与后端版本清单 `2ff7f0a7…` 逐字节一致），鸿蒙包是 9-01 构建的签名 HAP。

**兼容性。** 桌面与手机同一套响应式代码；尊重系统「减少动态效果」设置（reduced motion 时星野静止、不动画）。原栖光后端的 `/api`、`/uploads` 反代路径未做任何改动，栖光 App 的接口不受影响；旧栖光静态素材保留在服务器目录中（已整站备份），未被删除。

**风险与需要验证的内容。**
- 安卓包是 8-16 构建的 v0.3.9，近期 RN 端改动不在其中；发新版需替换 `landing/public/dl/` 并更新 `src/config.ts` 的版本号与文件名。
- 鸿蒙 HAP 为 debug 签名包，普通用户侧载安装可能受华为限制，正式分发需走 AGC。
- 服务器 web 根目录仍混有栖光旧素材（整站备份 120MB 在 `/home/ubuntu/site-backups/`），确认官网稳定后可清理旧文件。
- 回滚方式：解压备份 tar 包覆盖回 `/var/www/yinji-smart-diary` 即可恢复原栖光站点。

### 第二层（技术实现）

- `landing/` 新增 Vite + React 18 + TypeScript 工程：`src/components/` 按区块拆为 Starfield / Nav / Hero / DumpSection / MemorySection / DeskSection / TheaterSection / DownloadSection / Footer / DownloadIcons；`src/hooks/`（useReveal 滚动显现、useReducedMotion）；`src/config.ts` 集中管理下载地址与版本号；样式集中在 `src/styles.css`（与静态定稿版逐字节一致，仅修正下载区星星与角色的间距）。
- 角色资产取自 `frontend-demo/assets/pets/miro/`，经 PIL 压缩为 webp（idle/blink/sit/wave 四态 + favicon），放在 `landing/public/assets/`。
- 安装包：`landing/public/dl/morning-android-0.3.9.apk`（37,934,011 B，与后端版本清单一一致）、`morning-harmony.hap`（3,387,108 B）。
- 部署（frontend-static-deploy 流程）：服务器端整站备份 `/home/ubuntu/site-backups/yingjiapp-com-20260902-140323.tar.gz` → dist 打包上传 → `rsync -a`（无 `--delete`）到 `/var/www/yinji-smart-diary`（属主归位 www-data），nginx 配置零改动 → 远端 `index.html` SHA-256 与本地一致（`9f46c3d8…`）。
- 验证脚本：`landing/scripts/shoot.cjs`（playwright 逐区块滚动截图 + 控制台错误收集，仅本地用）。

### 验证记录

- 本地 preview 与线上 https://yingjiapp.com/ 各截 6 区块 × 桌面(1440×900)/移动(390×844) 双视口，渲染一致，`NO_CONSOLE_ERRORS`。
