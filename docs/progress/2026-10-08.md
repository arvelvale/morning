## 官网：配乐重写为「跟着短片时间走」；顶部导航重做

### 配乐（landing/src/sound.ts）

- **旧版的问题**：音乐按音频时钟自己循环，从按下「声音」那一刻的第 0 拍开始，和弦与剧情对不上；短片滚出视口自动暂停时音乐还在响；A 小调和弦的垫音用了 `root*2.5`（大三度），弹出来是 A 大调，和旋律里的 C 冲突；没有混响，正弦波干声发薄。
- **现在**：乐谱写在短片时间上（72 BPM，12 小节 = 40 秒），短片每帧报告时间，配乐把之后 0.3 秒的音符排进音频时钟，并扣掉输出延迟。短片停下（手动暂停 / 滚出视口 / 切后台）0.3 秒内淡出，继续时从当前和弦淡入。
- 和弦跟剧情：清晨 C → 念头飘出 Am、Dm、G7sus4（悬着）→ 接住 C → 入夜 Am、F、Em → 字幕 Fm6 → C；入夜后垫音低通从 1900Hz 收到 750Hz、旋律变轻。
- 动作音：波比四跳、放杯子、四张纸条冒出、火锅被吃掉、接住、光点入星、抱住星星，时间取自 pet-rig.js 的 HOPS / NOTES / MOTES。
- 减弱动态时短片不播，声音按钮一并隐藏。

### 导航（Nav.tsx + styles.css 导航段）

- 三栏 Grid（1fr auto 1fr），分区链接在整条导航里真正居中（实测偏差 0px）；宽度与正文容器一致，logo 与正文左缘对齐（≥1180px 时）。

- 860px 以下收成菜单：导航条内向下展开，Esc 收起并把焦点还给按钮、点外面 / 点链接收起、拉宽到桌面自动收起；收起时菜单链接不进 Tab 顺序。380px 以下隐藏「Morning」。
- 「倾倒」保留原文：对应分区是「倾倒思绪」（把待办、念头一股脑倒出来再整理），不只是倾诉情绪，和 App 的「一股脑倒出来」同一个概念。

## Android 启动闪退：常驻陪伴服务前台注册超时

### 原因与修复

- OPPO PJE110（Android API 36），已装 `com.morning.app` 0.3.13 / versionCode 16。真机崩溃日志多次记录 `ForegroundServiceDidNotStartInTimeException`，对象是 `CompanionForegroundService`，系统因此终止整个 App。
- 代码中「停止陪伴」通过 `startService(ACTION_STOP)` 实现，首次 token 尚未恢复时也会创建服务；启动/停止异步调用可交错。此外已有运行状态分支只刷新通知，不重新确认前台注册。这些是代码中的生命周期风险；日志未单独证明每一次超时的精确事件顺序。
- 服务 `onCreate` 立即注册前台通知，每次启动均调用 `startForeground`；停止入口改为 `stopService`，不创建服务。通知暂停入口先移除前台通知，再按 `startId` 停止，销毁时移除计时器和通知。
- JS 启动/停止调用串行化，失败返回 false 且不阻塞后续任务；新增 `npm run test:companion`。

### 验证进度

- 生命周期队列回归测试与原生源码防回退检查通过；`npm run typecheck`、`git diff --check` 通过。源码防回退检查不等同 Android 生命周期实测。
