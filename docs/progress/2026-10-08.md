# 2026-10-08 开发日志

## 官网：配乐重写为「跟着短片时间走」；顶部导航重做

### 配乐（landing/src/sound.ts）

- **旧版的问题**：音乐按音频时钟自己循环，从按下「声音」那一刻的第 0 拍开始，和弦与剧情对不上；短片滚出视口自动暂停时音乐还在响；A 小调和弦的垫音用了 `root*2.5`（大三度），弹出来是 A 大调，和旋律里的 C 冲突；没有混响，正弦波干声发薄。
- **现在**：乐谱写在短片时间上（72 BPM，12 小节 = 40 秒），短片每帧报告时间，配乐把之后 0.3 秒的音符排进音频时钟，并扣掉输出延迟。短片停下（手动暂停 / 滚出视口 / 切后台）0.3 秒内淡出，继续时从当前和弦淡入。
- 和弦跟剧情：清晨 C → 念头飘出 Am、Dm、G7sus4（悬着）→ 接住 C → 入夜 Am、F、Em → 字幕 Fm6 → C；入夜后垫音低通从 1900Hz 收到 750Hz、旋律变轻。
- 动作音：波比四跳、放杯子、四张纸条冒出、火锅被吃掉、接住、光点入星、抱住星星，时间取自 pet-rig.js 的 HOPS / NOTES / MOTES。
- 减弱动态时短片不播，声音按钮一并隐藏。

### 验证
