# 2026-10-07 开发日志

## App 改版第二稿落地：夜空主卡、「今天接住了 N 件事」、真实界面上的新手引导

规格正本：[docs/specs/2026-10-07-app-redesign-v2.md](../specs/2026-10-07-app-redesign-v2.md)；交互设计稿 `design-demos/app-redesign/index.html`。

### 产品语义

- **为什么改**：用户指出四个问题——米白 / 浅金 / 白色太多没有层级；猫像插图，没和操作结合；首页没把「接住了几件事」这个核心概念表现出来；不要多页轮播式新手引导。
- **配色**：米白只做底色，首页最重的一块是「米露的夜空」深靛主卡；金色只给星星（被接住的东西）；待办 / 灵感 / 情绪 / 片段各一个颜色。主按钮、底栏选中态改为深靛（夜间浅薰衣草）。
- **字体**：标题和米露说的话换成霞鹜文楷（随包子集，改名 Miaoling Kai），正文仍是系统字。
- **首页**：第一眼是「今天接住了 N 件事」（72px 星星色）和四类拆分；「接下来」写着明早的提醒和今晚 21:30 的信；最底下只留一个主操作「一股脑倒出来」，其他聊法收进「+」。
- **猫和操作绑在一起**：打字时它竖耳朵；倒出来的话变成纸条飞进它抱着的星星；后端每分类好一条，数字跳一下、星星闪一下；等分类时它在思考，接完开心一会儿；引导时它的视线跟着高亮处走。
- **明早提醒**：「今天接住的」里，待办可以点「明早提醒我」，后端记下截止时间，手机上排一条明早 8 点的本地通知。
- **新手引导**：不再有独立教程页。登录 / 注册后直接进真实首页，遮罩只亮一个真实元素，米露说一句话；六步都要真的做才推进（戳它 → 倒出来 → 点开数字 → 设明早提醒 → 去信箱 → 摸信封），点暗处不推进，随时可跳过；「我的」里能重走。片场不进第一次引导。
- **登录页**：夜空里的米露听你输入，输密码时用粉色肉垫捂住眼睛。
- **信箱**：今天的信没到时，顶上放一封封好的「今晚的信」，米露在旁边攒今天的事。
