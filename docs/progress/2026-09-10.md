# 2026-09-10 开发日志

## 安卓 0.3.10 编译与双通道发布

### 产品语义

用当前工作区最新代码重新编译安卓正式包，版本从 0.3.9 升到 **0.3.10**（versionCode 12→13），这样已装 0.3.9 的用户能收到应用内更新提示。本地旧版 APK（release 输出与 landing 的 0.3.9 包）已删除。

双通道已切换到同一份新包：
- 官网 https://yingjiapp.com/dl/morning-android-0.3.10.apk（旧 0.3.9 路径已被 SPA 回退，不再提供旧包）
- App 内更新通道 http://223.109.142.152:8000/static/download/morning-0.3.10.apk，`/api/v1/app/version` 为 0.3.10 / version_code 13 / SHA-256 `bc4810aa…`

### 技术实现

- 版本号同步：`build.gradle` / `app.json` / `package.json` / `landing/src/config.ts` / `backend/app/app_version.json` changelog。
- 构建：`frontend-demo/android` 下 `:app:assembleRelease`，仅 arm64-v8a；产物 40,672,292 B，debug.keystore 签名（与历史包一致）。
- 环境坑（本机）：
  1. **PATHEXT 被写坏**（变成未展开的 `%PATHEXT%;.RB;…`），导致 `cmd` 找不到 `node`，Gradle settings 阶段失败。构建脚本内重置 PATHEXT 后恢复。
  2. **Maven Central TLS 握手被掐**，`checker-qual:3.41.0` 下不下来；在 `android/build.gradle` 加了阿里云镜像，并把 checker-qual 强制到缓存里已有的 3.33.0。
  3. 官网服务器是 **107.155.55.76**（ubuntu），与后端 223.109.142.152 不是同一台；`deploy/sync_landing_site.py` 负责 dist → `/var/www/yinji-smart-diary`。
- 发布脚本：`deploy/publish_apk.py`（更新通道）+ `deploy/sync_landing_site.py`（官网）。

### 如实说明

- 新包只做了编译级与线上下载校验，**未真机安装验收**。
- 仍为 debug 签名；正式分发若要应用商店需换 release keystore。
- 仓库工作区仍有大量未提交改动（品牌更名等），本次未 commit。
- `android/build.gradle` 里的阿里云镜像与 checker-qual 强制是本机构建 workaround，若换环境可按需去掉。
