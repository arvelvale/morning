# 2026-10-09 开发日志

## 片场人物模型重做（App 与离线剧场共用一份）

### 产品语义

- **之前**：人物像木头关节人偶——六边形的脸、碗盖头发、香肠一样的腿、肩上两个“护肩球”，脸只有两个小点。
- **现在**：圆润的玩偶质感（和米露、波比同一个气质）。脸有带高光的黑亮眼睛、眉毛、小嘴、腮红，哭的时候带泪；头发有侧分的发际线，四种发型（短发/长发/马尾/发髻）各有轮廓；手有拇指；鞋有鞋底；大衣有腰带、翻领、围巾，校服有领口和领带，连衣裙有白领和束带；老人戴圆框眼镜。
- **新增的动作细节**：腿多了膝盖——坐着时小腿会垂下来，走路时摆腿的那一侧会屈膝。
- **顺带修好的 bug**：行李箱的箱体原来根本没有加进场景（只有包角和拉杆），现在能看到整只箱子。
- **没变的**：人物类型/体型/服装/发型的取值、所有姿态、握手机/递东西的位置、坐姿贴合座位的精度，布局引擎和后端白名单都不用改。
- **离线剧场（theater/）**：不再维护第二份人物代码，直接引用 App 里的这一份，两边长得一样。

### 如实说明

- 三角形预算从 3400 提到 5600（单人实测 4400–5500），mesh 数从 ≤36 降到 ≤28。一个场景最多 3 人，量级仍小；**没有在真机上测帧率**，需要在低端安卓上看一眼。
- 离线剧场里的露营地 / 卧室 / 海边三个夜景原本就很暗，这次没动。
- `test-scene-visual` 里有一条“firewood 的 color 为 undefined”的 three 警告，是旧问题，没处理。

### 技术实现

- 拆成模块，`index.ts` 只当“总调度”按骨架（髋→膝、肩→肘、颈）装配：
  `geo.ts`（几何小工具，同一个 pivot 下的片合并成一个顶点色 mesh）、`head.ts`（蛋形头骨 + 发型）、`face.ts`（五官/表情/眨眼）、`body.ts`（躯干/衣服/手臂/腿/鞋/书包）。
- 头部转动的轴从头心移到脖子根；`poses.ts` 的 `FigureParts` 增加可选的 `kneeL/kneeR`。
- 验收：`npm run typecheck`、`scripts/test-figure-model.cjs`（预算改为 28 mesh / 5600 三角形）、`test-scene-layout/s2/visual` 全部通过（坐姿贴合误差 0.00024 m，握点误差 1e-15）。

## 片场背景与道具优化

### 产品语义

- **天空**：白天、黄昏、阴雨、夜里都有了软边的云（慢慢飘），黄昏的云被夕阳染成暖粉；月亮从“灰盘”换成带月海斑块和柔光的月亮。
- **地面**：不再是一张死平的纯色——有大块深浅色斑，近亮远沉；户外撒了几百簇小草（偶尔一朵小花），一次绘制，开销很小。
- **远山**：绕一整圈、没有断口，山脚融进雾色，不再是一条硬边的色带。
- **黄昏地面**原来近乎黑褐色，提亮后能看清；**露营地**预置场景原来几乎全黑，现在冷色月光打底、篝火仍是唯一的暖焦点。
- **道具**：松树（粗树干 + 逐层收窄的锯齿冠）、灌木（团块 + 小红果）、岩石（带苔藓的两色石 + 小石子）、帐篷（两面屋顶明暗交替、深色内衬与地布、门框缝线、拉绳与地钉、门前小垫）重做。

### 如实说明

- 离线剧场 `theater/` 只共用了人物模型；它自己的天空/地面/场景灯光是旧代码，**没有同步**（它的露营地、卧室、海边夜景仍然很暗）。
- 预置“露营地”场景里的帐篷是它自己手写的一份（又大又红的三角棱柱），没换成新帐篷。
- 云用一张 256² 的预计算噪声纹理采样，没有在着色器里现算噪声：第一版现算时在黄昏云里出现了一格一格的色块（手机低精度会更严重），已经换掉。
- 没有在真机上量帧率；新增的几何很少（草丛 420 簇 ≈ 一次绘制 3.8k 三角形）。

### 技术实现

- `utils.ts`：`createSkyDome` 加云层（`clouds` 参数 + `userData.update`），`createMoon` 改着色器面片，`createMountains` 加 `haze` 和整圈，`createGround` 改为极坐标顶点色圆盘（活动区保持水平），新增 `createTufts`（InstancedMesh）。
- `mood.ts`：每种情绪预设加 `clouds`；黄昏地面/补光提亮。`assemble.ts` 接入云、山雾、草丛。预置场景 campsite/seaside/trainStation/bedroomWindow 调整灯光与云；删除海边旧的网格云团。
- 道具：`props/nature/{shape,rock,bush,createPineTree,tent}.ts`。

## 补齐两块短板：单房间骨架 + 校验回传环

对照朋友编辑器的思路（先定区域、再往里装；AI 看结果再调），Morning 原来缺这两块。

### 1. 单房间骨架（先定房间，再放家具）

- **用法**：语义规格新增 `room`（宽/深/高、墙色/地色、`openings` 门窗洞口）；零件的 `at` 新增 `edge: back|left|right`（靠墙）。LLM 仍然不写坐标。
- **几何**：`layout/room.ts`（纯函数，构造器/求解器/校验器共用同一份）、`props/furniture/room.ts`（地板+后墙+左墙，门窗是**真洞口**，墙/地/踢脚线合成 1 个顶点色 mesh，整间 ≤30 mesh / ≤2500 三角形）。只画后墙和左墙（镜头在右前方，剖开的玩偶屋），右墙/前墙不画但家具仍被限制在四面墙内；洞口写在右/前墙会被就近改到后/左墙，并在报告里记 `ROOM_OPENING_REMAPPED`。
- **求解器**：`at.zone/side` 在有房间时按屋内三等分；`edge` 贴墙用旋转后的真实包围盒贴合、正面朝屋内；边界按内墙把整件推回（原来是固定 ±11m）；窗帘没写靠墙时自动贴到第一扇窗那面墙。
- **新增校验**：`DOOR_BLOCKED`（门前 0.9m 有家具）、`WINDOW_BLOCKED`（高过窗台的家具遮窗）、`ROOM_OBJECT_TOO_BIG/OUTSIDE`、`ROOM_OPENING_DROPPED`、`EDGE_WITHOUT_ROOM`。人物站在门口/窗边不算堵。
- **顺带修的老 bug**：独立的 `window` 零件被放到 y=-1.13（整扇窗在地板下面），`departureBoard` 同理。原因是求解器按 `-minY` 把自由件按到地面，而这两个构造器把离地高度写在根节点上、装配时又被 `pos` 覆盖。现在高度放在内层，`PROP_META.hung` 标记免于贴地。
- **夹具**：`studyNight`（深夜书房：后墙窗、左墙门、书桌书架靠后墙、床靠左墙）。

### 2. 校验回传环（报告 → 模型再改一轮）

- **为什么在端上做**：求解器/校验器是 TypeScript 在端上跑，后端 Python 没有第二份；所以端上解算 → 发问题 → 后端让模型改稿 → 端上重解、比分。
- **前端** `layout/review.ts`：只数 unresolved/degraded 且"改规格能解决"的问题（`CODE_WEIGHT`）；候选稿必须**分数严格更低、人物一个不少、室内外与时段不变**才采纳；最多 2 轮；改过的记录写进 `spec.review`，下次打开不再重复请求。`screens/scene/useReviewedSpec.ts` 在 ScenePlay 里后台跑（先画原稿，延迟 1.2s 开始，采纳后换上并存回），任何一步失败都静默保留原稿。
- **后端** `scene_spec.py`：`revise_scene_spec`（问题→改稿提示，`REVISE_HINTS` 白名单 code，不在表里的 code/不存在的 id 一律丢弃；人物外观、env、mood 以原稿为准）、`prepare_saved_spec`；`scenes.py` 新增 `POST /scenes/{id}/spec/revise`（只返回候选稿、不入库；先记账再调模型，每个场景一辈子最多 4 次）和 `POST /scenes/{id}/spec`（存回，重新清洗并校验）。
- **真实模型实测**：用新提示词让模型写"深夜卧室打电话"，第一稿里床挡了门、挡了窗、还压在妈妈身上（校验分 8）；按报告改一轮后分 3，床挪到右墙，门/窗/妈妈三项都解决，剩床与坐着的学生有 9cm 重叠，要靠第二轮。

### 如实说明

- **没有部署**，也没有提交。后端要部署后，线上旧版本的 App 仍走旧流程（新字段 `room`/`edge`/`review` 旧前端会忽略，不会崩，但也看不到房间）。
- 改稿是在**用户打开场景之后**后台做的，所以第一次打开可能先看到原稿、1~几十秒后换成改好的版本（会重建一次场景）；改好后存回，第二次打开直接是新版。若想"生成时就改好"，需要把求解器搬到后端（Node 或 Python 重写），这次没做。
- 校验分只覆盖"布局类"问题；相机取景、座位锚点、握点这类引擎自己的事不进回传环。
- 没有真机测试；房间材质在低端安卓上的表现只在电脑上看过。
- 右墙/前墙不画，镜头转到屋外一侧会看到屋子是敞开的（玩偶屋式）。
- 运行测试：`node scripts/test-scene-room.cjs`（前端，14 项）、`scripts/test_scene_spec_revise.py`（后端，8 项）；原有 `test-scene-layout/s2/visual/figure-model` 与 `test_scene_semantic.py` 仍通过。
