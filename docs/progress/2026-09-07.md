## 3D 人物模型 · 第一轮精修

### 原因 → 修改

保留现有低多边形比例和年龄/服装/发型字段，不改为大头 Q 版，也不新增模型服务或纹理依赖。

- 旧头发帽壳遮住眼部、五官部分埋进脸内：抬高帽壳边缘，五官移至表面外侧；方块刘海、后脑与长发改为低面数圆润轮廓，长发/马尾随年龄头部比例缩放。
- 哭泣、争执也一直微笑：独立 `figure/face.ts`，按既有 pose 分为注视、温和、低落、说话表情，增加只更新缩放的眨眼。这里仅表现已指定姿态，不从用户文本推断情绪。
- 胸球与圆筒有接缝：改为单个旋转轮廓躯干；修正藏在头内的脖颈、悬在腰后的围巾，衣裤深浅分离。
- 行走有两套脚，其中一套不跟腿动：删除静态脚和重叠鞋头，每条腿只保留一只圆润鞋子。
- 待机微动覆盖回头角度：在既有姿态角上叠加微动，保持 `lookingBack` 语义。

### 验证与开销

- `node scripts/test-figure-model.cjs` 退出 0：4 年龄 × 4 发型 × 4 服装 × 5 姿态，共 320 组合；检查几何预算、有限矩阵、每人两鞋、行走鞋位变化、表情和回头保持。
- 基础成人短发便装：31 → 26 个网格；2,372 → 2,556 个三角形（增加约 7.8%）。320 组合最高 31 网格 / 3,092 三角形。网格数不等同 GPU draw calls；没有据此宣称帧率提升，手机 GPU 开销仍待实测。
- 最终 `node scripts/test-scene-s2.cjs` 退出 0：11 项原回归 + 10 组 S2；座面 80 组合/400 时刻最大误差 0.006949714m，持物 336 组合/2016 时刻最大误差 1.95×10⁻¹⁵m。`npm run typecheck`、`git diff --check` 均退出 0。
- 浏览器实际检查旧版/新版同视角近景；核实实际 CSS 视口 390×844 与 1440×900。新版眼睛不再被帽壳遮住、鞋部与躯干接缝改善；桌面四年龄组合能同时检查发型、裙装、校服、外套和行走/挥手。
- 复现入口：本地 Expo `?screen=scene3d-preview` →「样例·绝对坐标」→ `figurePortrait` / `figureFamily`，夹具在 `generated/samples.ts`。使用现有预览页面，不增加正式产品页面。
