# 2026-10-11 开发日志

## 0.3.15 自有更新通道与后端上线

### 产品语义

- 应用内「检查更新」现在可获取 0.3.15，不再只有 GitHub 和官网能下载这一版。复用已发布安装包，没有为了部署另行构建新包。
- 新房间生成与问题回传改稿的后端能力上线，客户端可以将布局问题交回模型修改，再自行决定是否采纳。
- 官网文案统一为「Android 7.0 起，建议 Android 10 及以上」：前者是安装包声明的最低版本，后者是建议版本，不把未测机型说成已验证兼容。安装包仅支持 64 位 ARM。

- 安装包、镜像、备份位置、回滚方法与待测项统一记录在 [0.3.15 发版记录](../releases/2026-10-11-0.3.15.md)，不在多处维护第二份运维正本。
