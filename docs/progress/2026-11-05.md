## 米露聊天记录明确待办，首页入口支持续聊

### 产品语义

- 自由聊天中说出明确安排（如「我明天上午11点有面试哈」）会写进现有待办列表，并在聊天里显示保存回执。普通闲聊、猜测和已结束的事不生成待办。写入待办与手机通知为两个动作。
- 首页聊天图标恢复最近一段已有消息的自由聊天。标题栏可以打开历史列表并向前翻页，仍可通过陪伴菜单开始新聊天。加载历史失败时可以重试。

### 技术实现与验证

- `chat_todos` 复用现有提取图、时间换算和 `MemoryStore`。含时间或动作线索的消息才调用待办提取，按标题与到期时间去重，持久化成功后发送 `todo.saved` 刷新待办。单次聊天回复最多读取最近 24 条消息，界面历史可读完整会话。接口见 [后端 API 设计](../../backend/docs/api-design.md#4-对话-conversations--已实现)。
- 本地通过聊天与待办 HTTP 回归、时间换算、记忆隐私、前端类型和待办提醒测试。公网验收从临时账号发消息，确认写入次日 11:00 的待办、读取同一会话和续发后的四条历史消息，测试数据已清理。
