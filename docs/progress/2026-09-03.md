## 首页闪退修复版 APK（0.3.9）双通道发布

### 产品语义

另一个 agent 修复了一个安卓端线上事故：首页页眉要显示农历日期，代码里调用了一个并不存在的农历库接口，导致首页启动直接闪退。修复方式是改用库里真实存在的接口，并加了一层兜底（fallback = 兜底，AI/库没给出合法值时系统拿来补位的默认值）：农历转换一旦失败，就退回显示普通公历日期——日期文案永远不值得让首页崩一次。同时给这个库补了类型声明，让编译器以后能提前拦住这种"调了不存在的方法"的错误。

今天 20:14 构建出的新安装包已确认包含修复，并完成了两件事的同步：官网（yingjiapp.com）安卓下载按钮背后的文件已替换为新包；App 内更新通道的服务器安装包与指纹也已同步，两个通道发的是同一份文件。顺带一个好消息：新包从 89.7MB 瘦到 38.8MB，因为这次只打包了现代手机使用的 64 位处理器（arm64）版本——官网标注的 Android 10+ 设备几乎全是 64 位，下载体积小了一半多。

需要留意的老问题仍在：版本号还是 0.3.9 没变，已经装过 0.3.9 的手机不会弹出更新提示，只有新下载和重装用户会拿到修复版。另外新包只过了编译级验证（类型检查通过、签名有效），未真机验收。

### 技术实现

- 事故与修复：`CompanionIdle.tsx` 使用新增 `frontend-demo/src/utils/lunar.ts`（农历+节气+时段词，solarlunar 库）；曾误调不存在的 `solarToLunar` 导致启动闪退，修复为真实 API `solar2lunar(y, m, d)` + try/catch 公历兜底；新增 `frontend-demo/src/solarlunar.d.ts` 类型声明（该包 d.ts 未在 exports 中暴露）。两个文件均为 09-03 新增、未提交。
