# 2026-09-25 开发日志

## 米露与波比换成程序化角色动画，官网改成手绘贴纸风

### 产品语义

- **为什么换**：原来的立绘是 GPT 生成的图，每加一个动作就要重新生成一次，同一只猫在不同图里长得不一样（米露前后出现过白色长毛月牙猫、3D 毛绒黑猫两套）；GIF 只有 256 色，也没法跟着通话状态动起来。
- **现在的形象**：扁平绘本贴纸风，全部用代码画出来，动作由骨骼驱动，所以任何姿势都是同一只猫。
  - 米露：黑猫、发光的椭圆眼、怀里抱着星星。矮、圆、动作慢；没有嘴，情绪靠眼睛和星星表达。
  - 波比：橘色虎斑猫，粉围巾加小太阳挂饰（晨光信使）。高、耳朵尖、会蹦；表情直接写在脸上。
- **App 里**：
  - 首页：白天待机，夜间打盹，星星变成小夜灯。
  - 语音通话：接通中竖起耳朵等你开口；通话中字幕上方的小猫跟着状态倾听、思考、回应。倾听时你说话越响，米露的星星越亮；回应时由角色自己合成说话节奏（角色说话期间麦克风音量被置零，拿不到 TTS 音量）。
  - 头像：选伙伴、我的、引导页都换成同一张骨骼渲染图。
  - 系统开了减弱动态时定格；App 进后台时暂停渲染。
- **官网**：首屏换成 40 秒程序化短片（黎明打盹 → 波比送水 → 念头碎片飘来 → 米露把最重的一片收进星星 → 入夜守着波比睡）；整站改成纸面贴纸风，文案保留原样（半角逗号改为全角）；新增「两位伙伴」板块；各板块里的米露都是活的，点一下会有反应。
- **一份源码四处用**：角色只写在 `pet-rig.js` 一个文件里，App 原生端（WebView 内嵌）、App 网页端、官网、以后的鸿蒙（ArkWeb）都加载它。

### 技术实现

- 运行时：`frontend-demo/src/pets/rig/pet-rig.js`（`window.PetRig.mountPet / mountFilm`）。角色画在一棵不挂进文档的 SVG 场景图上，每帧由一个小解释器画进 canvas。贴纸白边和投影是同一套骨骼的两份副本，只留外轮廓，强制涂成纯色并加粗描边。
- 同步：改完运行时运行 `npm run rig:build`（`scripts/build-pet-rig.mjs`），生成 `petRigSource.generated.ts`（原生端内嵌用的字符串），并拷到 `landing/public/pet-rig.js` 和 `design-demos/pet-motion/pet-rig.js`。**不要手改副本。**
- App：`PetRigView.tsx`（原生：react-native-webview，状态通过 injectJavaScript 下发，音量按 66ms 节流）、`PetRigView.web.tsx`（网页：直接执行运行时）。`HomePetArtwork` 对外 props 不变，新增可选的 `mood` / `level`。静态兜底图 `assets/pets/rig/{miro,bobi}-{idle,sleep}.png` 与动画第一帧同机位，淡出切换不跳；加载失败时一直显示。
- 新依赖：`react-native-webview@13.13.5`（原生依赖，**必须重新打 APK**，不能靠热更新推送）。
- 首页原来给 GIF 配的地面椭圆投影删掉了，骨骼动画自带接触阴影和贴纸投影。
- 演示页：`design-demos/pet-motion/index.html`（短片，带控制条，`?t=` 跳帧）、`pet.html`（桌宠状态台：六种状态、昼夜、音量）。
- 性能：原型最初在本机核显（Iris Xe）上只有 7.5fps。用 Chrome 性能追踪逐项定位后改掉三处：SVG 滤镜每帧重新光栅化、SVG 文字每帧重新排版、6 个全屏混合层。现在短片在同一台机器上 52–60fps。
