# 喵灵 0.3.17：待办按真实时间提醒、待办 Tab、来信不复读

## 这一版改了什么

- **时间识别**：倾倒抽取时注入「现在」（东八区），待办输出 `due_at`，并把正文里的今天/明天改写成具体日期；`dump_ingest` 写入 `due_date`（UTC）。约定：东八区本地 00:00 = 只有日期（`has_time=false`）。待办接口入库前统一换算为 UTC（修复 SQLite 丢时区导致的 8 小时偏差）。
- **来信不复读**：晚间信只取当天素材，不再回落旧记忆；素材带「X月X日记下」前缀；近两周提过的记忆（`attachment.material_ids`）不再取用；长期记忆上下文与主动问候素材带日期，过期待办标「已过期」；睡前提醒注入当前时间并禁止编造待办。
- **App**：
  - 底栏 今日 / 待办 / 信箱 / 我的。
  - 待办页分「待办 / 随手记」两栏；提醒与事情时间分开：有时刻的提前 15 分钟，只有日期的当天 8 点，没时间的明早 8 点；提醒状态存本机。
  - 今日页顶部出「要提醒你吗」横幅，首次点击时申请通知权限。
  - 「片段」改名「记下的瞬间」，可以点开看原话。
  - 首页右上角加聊天入口，桌宠头像改用形象图。
  - 夜间文案只在 20:00 到次日 05:00 冒泡。
