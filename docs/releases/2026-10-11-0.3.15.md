# 喵灵 Android 0.3.15：安装修复 + 片场新建模

## 为什么发这一版

朋友从 GitHub Release 下载 0.3.14 安装时报「解析失败：安装包没有签名文件」。排查结果：

- 他下载的文件与本机构建产物哈希一致、大小一致（35,272,636 字节），不是传输损坏；
- `apksigner verify` 显示 0.3.13、0.3.14 都**只有 v2 签名，没有 v1（JAR）签名**（包里没有 `META-INF/*.RSA`）；
- 原因是 `minSdk` 为 24 时 Android Gradle 插件默认只写 v2；部分机型的安装器只认 v1。

修复：`android/app/build.gradle` 显式 `enableV1Signing true` / `enableV2Signing true`，**沿用同一把 debug 密钥**（证书 SHA-256 `fac61745…3b9c`），已装用户覆盖升级不受影响。

同时发布工作区里已完成但此前未发布的片场改动，所以版本递增到 0.3.15 / versionCode 18：

- 片场人物重新建模（圆润玩偶质感、带高光的眼睛、四种发型、有拇指的手、有鞋底的鞋、膝盖）；
- 片场背景与道具重做（云、柔和的月亮、地面草丛、远山绕整圈、松树/灌木/岩石/帐篷）；黄昏与夜里的场景提亮；
- 单房间骨架（`room`/`at.edge`）与校验回传改稿环——**客户端已包含，但依赖后端新接口，后端尚未部署，所以这一版里用户看不到**；旧后端下客户端静默保留原场景，不报错。

## 构建与验证

- PowerShell `:app:assembleRelease -PreactNativeArchitectures=arm64-v8a`，退出 0，耗时 2 分 58 秒。
- APK：包名 `com.morning.app`，versionName 0.3.15 / versionCode 18，minSdk 24，仅 arm64-v8a，35,375,931 字节。
- 签名：`apksigner verify --min-sdk-version 21` 显示 **v1 与 v2 均通过**；证书 SHA-256 与 0.3.14 一致；`zipalign -c` 通过。
- SHA-256：`f3355a0bf8873333258af88b17237314b9b8973ddcc906ccd8976d0f7b68526a`。
- 测试：`tsc --noEmit`；`test-scene-layout / s2 / visual / figure-model / scene-room / scene-review / update-policy / companion-lifecycle / voice-guards`；后端 `test_scene_semantic.py`（13 项）、`test_scene_spec_revise.py`（8 项）全部通过。
