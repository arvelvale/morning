# 喵灵 Android 0.3.14：启动闪退修复

## 原因与修改

OPPO PJE110（Android API 36）的 0.3.13 崩溃日志多次记录 `ForegroundServiceDidNotStartInTimeException`，指向常驻陪伴服务。服务未及时完成前台注册，系统终止整个 App。

修复服务创建时的前台注册，重复启动也确认前台状态；停止入口使用 `stopService`，不再因停止请求创建服务；JS 调用串行化，避免 token 恢复、宠物更新的启动/停止交错。用户已反馈相同修复逻辑的 0.3.13 测试包可以正常运行。

正式发布递增到 0.3.14 / versionCode 17。客户端按版本名称判断更新，继续使用 0.3.13 无法提醒已装旧 0.3.13 的用户。同步 app.json、package.json、package-lock.json、Gradle、版本清单和官网下载配置；app.json 补充 Android versionCode，避免后续 prebuild 丢失版本码。
