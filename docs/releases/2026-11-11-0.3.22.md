# 喵灵 0.3.22：聊天发图与拍照、自带密钥（未开放）、通知分频道与悬浮米露

## 这一版改了什么

- 聊天可发图片或直接拍照（一次最多 3 张，单张压缩后 ≤1.5MB）；图片存在服务端持久卷 `/data/chat_images`，读取需登录且只能读自己的，不进记忆。
- 文字聊天的场景邀请：关键词粗筛命中后才调模型识别，回复说完再出邀请卡片。
- 文字模型路由：阶跃 step-3.7-flash 优先，失败时退到 DeepSeek（线上尚未配置 `DEEPSEEK_API_KEY`，备用暂不生效）。
- 自带密钥（BYOK）：客户端「模型与密钥」页 + 后端请求头透传；只在 https / 回环地址上发送密钥，线上仍是明文 http，所以本版该页只读、实际不生效。
- 合入 0.3.20 / 0.3.21 未公开的改动：聊天记待办与回执、首页续聊与历史翻页、文案调整；安卓常驻通知分频道、通知快捷操作、悬浮米露、开机自启。
