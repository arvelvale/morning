# 喵灵 0.3.16：信箱改版、「有句话」、沉睡用户停发

## 这一版改了什么

- **沉睡用户停发**：新增 `users.last_active_at`（迁移 020）。连续 3 个东八区自然日没打开 App，第 4 天起六个会调模型的定时任务（晚间来信、周报、睡前提醒、主动信号、做梦、场景推荐）跳过此人；任何一次打开立即恢复。后台自动请求（60s 来信轮询、位置、信号样本上报）不算打开。可用 `DORMANT_AFTER_DAYS` 调整，`<=0` 关闭。
- **「有句话」**：场景邀请信改为结构化的「你说过 / 可以这样开口 / 对方可能会说 → 你可以接」；素材加入文字聊天里用户自己的话；原话必须逐字出自素材；每 7 天最多 2 封；**不再夜里预搭场景**，用户点「进去说说看」时现搭（本地实测约 40 秒，客户端超时已改为 240 秒）。
- **App**：底栏去掉片场（今日 / 信箱 / 我的）；信箱按原型改版（`docs/design/prototypes/mailbox-redesign`）；来信显示时分；点米露、波比有音效；回到前台时调用 `POST /api/v1/users/me/active`。
- **官网**：去掉页脚 GitHub 链接；配乐默认开启（首次交互才出声）；桌宠点击音效。

## 如实说明

- 没有真机验证：信箱改版、音效、「有句话」只在网页版里走过；低端安卓的表现未知。
- 旧版（0.3.15 及更早）用户点「有句话」进场景：客户端 15 秒超时，而现搭约 40 秒，第一次会提示「等太久了，再试一次」，场景实际已在后台搭好，再点即可进入。更新到 0.3.16 后没有这个问题。
- 迁移回填只看聊天记录：只读信不聊天的人上线后会被暂时判为沉睡，下次打开 App 的任何业务请求都会恢复。
- 官网的「场景重演」版块与比赛表单文案仍按「片场 Tab」描述，尚未同步。
- 本地生图接口返回 404，网页版验证时场景背景是暗色兜底；生产配置不同，未在生产上点进去现搭（避免用真实账号产生数据）。
