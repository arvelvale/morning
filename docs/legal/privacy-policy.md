# Morning 喵灵隐私政策

生效日期：2026 年 11 月 13 日  
版本：1.0

## 1. 适用范围

本政策适用于 Morning 喵灵（以下简称“喵灵”或“我们”）提供的 Android 安装包、Web 端、官网及相关服务。喵灵是 AdventureX 黑客松团队项目，运营主体为 Morning 喵灵团队（无公司主体），联系人孙明锐，联系邮箱：djia54995@gmail.com。

## 2. 我们收集哪些信息

### 2.1 账号信息

- 用户名、邮箱、密码哈希、显示名称；
- 邮箱验证码、登录状态、令牌刷新记录；
- 最近活跃时间、注册时间；
- 是否使用自带模型密钥（只记录“是/否”，不保存你的密钥）。

我们不收集你的通讯录、短信内容，也不会读取你未主动选择的相册内容。

### 2.2 你主动提供的内容

- 对话文本、语音转写文本、你发送的图片；
- 记忆条目（待办、小结、灵感、情绪、片段）、场景、信件、桌宠选择、交接信；
- 偏好设置：提醒时间、主动陪伴开关、寄存天数、是否保留原始倾诉、画像学习开关等。

### 2.3 设备权限与主动信号（需你授权或开启）

- **麦克风**：用于语音转文字与实时语音对话。根据 App 权限说明，我们不保留原始录音；转写文本按对话与记忆规则处理。
- **通知、悬浮窗、前台服务、开机自启**：用于桌宠显示、提醒与主动陪伴。
- **运动/驾驶检测**：客户端在本地计算速度与活动类型后上传，不上传原始 GPS 轨迹。
- **手机使用摘要**：在你授权后上传每日屏幕时间、拿起次数、夜间使用时长、应用使用时长；不上传应用内具体内容。
- **位置**：仅在你主动提供或开启相关功能时，保存最近一次模糊位置（城市、经纬度）用于天气与主动陪伴；不持续采集轨迹。

### 2.4 自动记录

为保障安全与排查故障，我们会记录必要的服务日志（请求时间、错误码、必要的技术信息）。日志按滚动策略限制容量，不用于训练或广告。

### 2.5 第三方返回的信息

- 阶跃星辰（StepFun）返回的文本、语音转写、语音合成、实时语音与图像处理结果；
- 彩云天气返回的天气信息；
- 推送服务返回的投递状态。

## 3. 我们如何使用信息

- 提供对话、睡前倾倒、信箱、记忆、场景演练、伙伴切换、主动陪伴等核心功能；
- 保障账号安全、服务稳定、故障排查与反滥用；
- 在你同意的情况下发送提醒与主动消息；
- 遵守法律法规要求。

我们**不会**将你的对话、记忆或敏感个人信息用于训练模型、出售、出租或用于广告投放。

## 4. 敏感个人信息

你的倾诉内容可能包含情绪与心理状态、健康情况、亲密关系、位置、语音等敏感个人信息。我们仅在提供核心功能所必需的范围内处理，并依据《个人信息保护法》取得你的**单独同意**。拒绝或撤回同意会导致依赖这些信息的功能不可用，但不影响其他功能。

我们不会基于这些信息对你作出具有法律效力或重大影响的自动化决定。

## 5. 共享、委托处理与第三方

我们不会出售你的个人信息。为提供服务，我们会委托以下第三方处理必要信息：

| 第三方 | 处理目的 | 涉及信息 |
|---|---|---|
| 阶跃星辰 StepFun | 文本生成、语音转写、语音合成、实时语音、图像处理 | 对话文本、语音、图片、必要的上下文 |
| 彩云天气 | 天气查询 | 模糊位置/城市 |
| Expo 推送服务 | 消息推送 | 设备推送令牌、通知内容摘要 |
| GitHub Pages | 官网/落地页静态托管 | 不涉及你的账号或对话数据 |

第三方仅按我们的指示处理信息，不得用于其自身目的。涉及跨境传输的，我们会另行告知并取得单独同意。

## 6. 存储地点与期限

- 原则上在中华人民共和国境内存储和处理；如未来使用境外服务，会另行告知并取得单独同意。
- 账号信息：保留至你注销账号。
- 对话、记忆、场景、信件：保留至你删除或注销账号。
- 临时思绪：默认 7 天到期硬删除，你可在 1–30 天内调整。
- 原始倾诉：你可以关闭“保留原始倾诉”；关闭后，提取成功即清除原文，只保留整理后的表层文本。
- 服务日志：按滚动策略限制容量，到期覆盖。
- 如启用备份，备份数据按备份周期滚动覆盖，不用于其他目的。

## 7. 你的权利

你可以：

- 查看、更正你的账号信息；
- 查看、删除记忆与对话；
- 关闭主动陪伴、画像学习、原始倾诉保留等开关；
- 撤回对敏感个人信息、通知、位置、运动/使用摘要的同意；
- 通过邮箱申请复制、导出或注销账号。

我们将在核验身份后 **15 个工作日内**处理。法律法规另有规定的除外。你可以通过 djia54995@gmail.com 联系我们，也可以向监管部门投诉。

## 8. 安全措施

- API 密钥只保存在服务端，前端不持有第三方模型密钥；
- 密码以哈希形式存储，不保存明文；
- 服务端访问控制、最小权限、日志滚动限制；
- 我们采用访问控制、密钥隔离、日志滚动限制等措施；我们正在完成 HTTPS 全链路加密。在 HTTPS 完成前，请避免在公共网络提交高度敏感内容；
- 发生个人信息泄露、篡改、丢失时，我们会按法律要求及时告知。

互联网没有绝对安全。请避免在公共网络提交高度敏感内容，并为账号设置独立密码。

## 9. 未成年人

喵灵面向 **18 周岁以上成年人**。14–18 周岁未成年人应在监护人同意和指导下使用；不满 14 周岁的未成年人不得使用。若我们发现未经监护人同意收集了未成年人信息，会尽快删除。

## 10. 政策更新

我们可能更新本政策。重大变更会通过应用内提示或官网公告通知；涉及敏感个人信息处理目的、方式、种类的重大变更，会重新取得你的单独同意。
