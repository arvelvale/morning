# Morning 今日待启与柔光珍藏册 · Figma Make 修改 Prompt

请修改当前 Morning App 的两个信箱栏目：

1. 将“今日待启”改为“周视图 + 所选日期的当日待办”；
2. 将“长久珍藏”改为“柔光珍藏册”；

保留现有信箱标题、四个栏目切换、奶油晨雾背景、底部 App Tab Bar 和其他页面，不要修改“桌宠来信”“三日寄存”及其他 App 功能。

基准设备为 iPhone 393 × 852 pt，遵守 iOS 安全区，保证页面可滚动且底部导航固定。

## 一、今日待启

### 目标

当前页面只是三张普通任务卡，缺少日期关系和用户主动添加能力。新页面应让用户通过一周视图切换日期，在下方查看和管理所选日期的待办，同时保持轻盈、低压力，不要设计成复杂日历或专业 Todo App。

### 页面结构

保留顶部：

- 标题“信箱”；
- 栏目切换：今日待启 / 桌宠来信 / 三日寄存 / 长久珍藏；
- 当前选中“今日待启”。

栏目切换下方增加周视图。

### 周视图

周视图由以下部分组成：

- 左上显示当前周范围，例如“7月21日—7月27日”；
- 右上使用克制的左右箭头切换上一周和下一周；
- 下方横向排列周一到周日；
- 每列显示星期和日期；
- 今天使用奶油黄色圆形或椭圆形背景；
- 当前选中日期增加一圈柔和暖白描边；
- 日期下方用 1–3 个极小暖黄色圆点表示当天有待办；
- 不使用红点、红色数字 Badge 或醒目任务数量；
- 支持左右滑动切换周；
- 点击日期后，下方内容使用 180–220ms 的淡入和 4–6pt 位移切换；
- 周视图保持紧凑，不要占据页面过多高度。

示例：

`7月21日—7月27日                         ‹  ›`

`周一  周二  周三  周四  周五  周六  周日`

`21    22    23    24    25    26    27`

### 所选日期标题

周视图下方显示：

- 主标题：“7月24日，星期五”；
- 次级文字：“今天有 3 件事等你接住”；
- 右侧放置小型胶囊按钮“＋ 添加”。

不要使用大型悬浮按钮。

### 当日待办

将原来的高大卡片改成更紧凑、清晰的任务行。

每个任务行包含：

- 左侧完成圆环；
- 中间任务名称；
- 任务下方显示来源或辅助信息；
- 右侧显示时间、截止日期或持续状态；
- 整行可以点击进入编辑；
- 向左轻扫可显示“编辑”和“删除”；
- 不使用高饱和 Emoji 作为主要图标；
- 不同任务不要使用完全不同的彩色图标。

示例数据：

1. “回复那封邮件” / 来源：“来自昨晚的整理” / 时间：“今天内”；
2. “和朋友见面” / 来源：“手动添加” / 时间：“15:00”；
3. “记得喝水” / 来源：“桌宠提醒” / 状态：“持续”。

“来自昨晚的整理”需要保留，让用户理解 Agent 在睡前替自己接住的内容进入了今天的计划。

### 完成状态

完成任务时：

- 圆环立即缩放至 0.96，再回到正常尺寸；
- 圆环填充为柔和奶黄色；
- 出现细小勾号；
- 文字轻微降低透明度并添加删除线；
- 动效控制在 180–240ms；
- 已完成任务进入页面底部的折叠区域“今天完成了 1 件”；
- 不使用积分、烟花、连续完成或成就系统。

### 空状态

所选日期没有待办时显示：

- 非具体桌宠的纸张或光点占位；
- 标题：“这一天还是空的”；
- 辅助文字：“可以先留一点位置给自己。”；
- 小按钮：“添加一件事”。

### 添加待办

点击“＋ 添加”后打开 Bottom Sheet。

字段只包含：

- 待办内容，必填；
- 日期，默认使用当前选中的日期；
- 时间，可选；
- 提醒，可选。

主按钮：“放到这一天”。

不要加入优先级矩阵、复杂分类、子任务、重复规则或项目管理功能。

Bottom Sheet 使用奶油白半透明材质，Backdrop Blur 40–56，圆角 28–32，使用 260–320ms 接近临界阻尼的 iOS 弹簧。

## 二、长久珍藏

### 目标

当前长久珍藏只是两张相同的大卡片，缺少“这是用户主动留下的人生物件”的感觉。将它改成一本轻盈、私密、可翻看的“柔光珍藏册”。

顶部不添加时间总结、数量总结或“这个月留下了几件东西”等文案。进入栏目后直接看到珍藏内容。

### 页面结构

保留顶部：

- 标题“信箱”；
- 栏目切换：今日待启 / 桌宠来信 / 三日寄存 / 长久珍藏；
- 当前选中“长久珍藏”。

栏目切换下方直接展示柔光珍藏册，不增加额外标题和总结。

### 柔光珍藏册

使用双列自适应 Masonry Layout，像一本安静的数字剪贴册。

每件珍藏根据内容类型拥有不同的“物件形态”，不要统一成相同尺寸的 App Card：

- 桌宠来信：折叠信纸或小信封；
- 今日洞察：手写便签；
- 灵感：半透明纸片；
- 场景结算：电影票、场记纸或剧本页；
- 音乐：小型唱片封套；
- 书籍：书签或窄版书页；
- 重要时刻：明信片或照片纸占位；
- 用户主动保存的一句话：短小纸条。

每件物件显示：

- 简短标题或第一句话；
- 保存日期；
- 内容类型的小型文字标签；
- 必要时显示桌宠名称；
- 不显示收藏数量、热度或评分。

### 视觉规则

- 物件宽度根据双列布局自动适配；
- 高度根据内容类型变化；
- 物件之间保持 12–16pt 间距；
- 不同纸张允许 `-1°～1°` 的轻微角度变化；
- 角度必须克制，不能显得凌乱；
- 使用暖白、奶油黄、淡杏、雾蓝和淡薰衣草；
- 纸张纹理控制在 1%–2%；
- 使用非常轻的折痕、纸张边缘或压痕；
- 阴影使用 `0 10 32 rgba(121,100,72,0.08)`；
- 不使用厚重玻璃拟态；
- 不使用统一白色大圆角矩形；
- 不使用照片墙式密集排布；
- 页面仍然保持大量呼吸感和留白。

### 示例珍藏

1. 折叠信纸：
   - “桐桐写给我的信”
   - “你已经做得比自己感觉到的更多了。”
   - 7月24日

2. 手写便签：
   - “我不是害怕失败，而是害怕拖累队友。”
   - 今日洞察
   - 7月18日

3. 场景票据：
   - “我终于把那句话说了出来”
   - 场景结算
   - 6月12日

4. 唱片封套：
   - “Bloom”
   - 桐桐夹在信里的歌
   - 6月8日

5. 短纸条：
   - “朋友说：你不用每次都表现得没事。”
   - 一句话
   - 5月28日

### 打开珍藏

点击一件珍藏时：

- 物件从原位置平滑放大到阅读视图；
- 背景轻微模糊并降低亮度；
- 进入和退出沿同一路径；
- 使用 260–320ms 的克制弹簧；
- 不使用 3D 翻页或夸张旋转。

阅读视图包含：

- 完整内容；
- 保存日期；
- 内容来自哪里；
- 当时由哪只桌宠陪伴；
- “移出珍藏”；
- 根据内容类型提供“回到对话”“再次体验场景”或“播放歌曲”等操作。

“移出珍藏”需要二次轻量确认，但不要使用危险感很强的红色弹窗。

### 筛选

在珍藏册右上角放置一个弱化筛选图标。

点击后可筛选：

- 全部；
- 来信；
- 洞察；
- 灵感；
- 场景；
- 音乐与书籍。

筛选使用 Bottom Sheet，不在主页面长期放置一排筛选胶囊，避免挤压珍藏空间。

### 空状态

没有珍藏内容时显示：

- 一张半透明的空信纸；
- 标题：“这里还空着”；
- 辅助文字：“只有你决定留下的东西，才会来到这里。”；
- 不放置强引导按钮。

## 三、整体视觉

继续使用当前 Morning 的奶油晨雾设计：

- 页面底色 `#FFFBF3`；
- 奶油主色 `#F6E7A8`；
- 淡杏 `#F3D8C7`；
- 雾蓝 `#DFE7F5`；
- 淡薰衣草 `#E9E4F3`；
- 主文字 `#4B463F`；
- 背景使用 3–5 个 Layer Blur 100–150 的大色团；
- 色团边界完全消失并缓慢流动；
- 低饱和、高明度、柔和暖色；
- 不使用纯黑、高饱和绿、霓虹色或蓝绿医疗色；
- 不使用红色数字角标；
- 不把页面设计成日历工具、任务 Dashboard 或普通收藏列表。

## 四、代码与交互要求

直接修改现有 React + TypeScript App。

建议组件：

- `WeekNavigator`
- `DayCell`
- `DailyTaskList`
- `TaskRow`
- `CompletedTasksSection`
- `AddTaskSheet`
- `KeepsakeAlbum`
- `KeepsakeGrid`
- `KeepsakeArtifact`
- `KeepsakeDetail`
- `KeepsakeFilterSheet`

数据模型至少包含：

- Task：id、title、date、time、source、completed；
- Keepsake：id、type、title、excerpt、savedAt、petName、source、content。

保证：

- 周视图可切换日期和周；
- 用户可以添加、完成、编辑和删除任务；
- 每个日期显示对应任务；
- 珍藏册根据类型呈现不同物件形态；
- 点击珍藏可以进入详情；
- 可以筛选和移出珍藏；
- 所有 mock data 独立管理；
- 393 × 852 pt 下无横向裁切；
- 主页面滚动时底部 App Tab Bar 固定；
- 不修改桌宠来信、三日寄存及其他页面。

最终效果：

“今日待启”让用户感觉事情已经被轻轻安排好，而不是面对任务压力；“长久珍藏”让用户感觉自己在翻看一组主动留下的人生物件，而不是浏览普通收藏列表。
